# Lesson 17 — Mongoose CRUD Operations

## Objective
Learn and implement CRUD operations using Node.js, MongoDB and Mongoose through a Product Management System.

## Concepts Covered

- Database connection using Mongoose and dotenv
- Schema and model creation
- Schema validation, default values and timestamps
- Document creation using `create()` and `save()`
- Reading documents using `find()`, `findOne()` and `findById()`
- Updating documents using `updateOne()` and `findByIdAndUpdate()`
- Deleting documents using `deleteOne()` and `findByIdAndDelete()`
- Database persistence verification using mongosh
- Asynchronous execution and error handling

## Environment Configuration

Create a `.env` file:

```ini
MONGODB_URI=mongodb://127.0.0.1:27017/mongoose_practice
```

## Run the Application

```bash
node index.js
```

## Learning Outcome

Successfully implemented all four CRUD operations and verified database persistence using MongoDB Shell.
